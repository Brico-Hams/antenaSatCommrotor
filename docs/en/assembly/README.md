# Illustrated assembly guide

Current Spanish additions: [BOM component image catalog](../../assembly/components/README.md),
[visual software installation](../../assembly/06-instalacion.md) and
[project review](../../PROJECT-REVIEW.md). The older English steps below
have not been synchronized with that expanded revision.

Every figure carries the BricoHams logo, a title block and the authors (Anatol EA5KAO, Diego EA5JEF, Pedro Roca Molina). They are generated by `scripts/make_assembly_figs.py` from the OpenSCAD models (`cad/`) and the Gerbers, so they cannot drift from the design. Figure text is English (`*.en.svg`); Spanish and Hungarian variants are in the same folder.

> **Status:** digital prototype, **not physically validated**. Figures are assembly aids, not machining drawings or manufacturing pinouts. The current ROTOR BASE is the **GT2 belt** design (`cad/belt_station.scad`); the planetary one (`cad/station.scad`) is LEGACY.
