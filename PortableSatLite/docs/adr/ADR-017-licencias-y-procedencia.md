# ADR-017: Licencias y procedencia

**Estado:** Aceptada

## Contexto
El código y el hardware deben ser redistribuibles.

## Decisión
Código original MIT; hardware CERN-OHL-S-2.0 (misma elección que el proyecto previo del usuario). Dependencias: Sgp4-Library (MIT), FastAccelStepper (MIT), TinyGPSPlus (LGPL-2.1). No se copió geometría de la ficha de Cults ni de repos sin licencia clara.

## Justificación y evidencia
Ver `docs/SOURCES.md`.

## Consecuencias y límites
Los PDF de KX4Z no se redistribuyen en este repo.
