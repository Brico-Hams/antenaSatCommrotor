## English
You are an independent auditor seeing this repository for the first time. Project: BricoHams portable amateur-radio satellite station, 145/435 MHz: CM5-controlled AZ/EL/POL rotor, two LimeSDR Mini (FM/AM/USB), Android app (tracking, SSTV PD120/PD180, APRS/AX.25), custom Raspberry Pi OS, ES/EN/HU docs, reference prices and JLCPCB files. Licences: software MIT, hardware CERN-OHL-S-2.0.

Tasks: (1) read `README.md`, `docs/REQUIREMENTS.md`, `docs/ARCHITECTURE.md`, `docs/VALIDATION.md`; (2) run `node --test tests/*.test.cjs` (expected 65 tests, 64 pass, 1 skipped), plus the Python tests in `tests/rotor` and `tests/radio_host` and the Android JVM tests if you have the environment; (3) check links, SVGs, EN/HU manifests and hashes; (4) verify every claim against evidence; (5) report contradictions, unsupported claims and safety risks (PTT, motors, LiFePO4 battery).

Honest claims to verify: this is an advanced DIGITAL prototype, NOT finished. A routed CM5 auxiliary board exists (`hardware/cm5`, KiCad 10.0.7: ERC 0, DRC 0) but is marked NOT MANUFACTURABLE and not to be energised: power stage DNP, no qualified fuses. No production BSP provider `portable_sat_rotor.hardware:cm5`. RF PA/filters and RHCP/LHCP switching unselected (Lime Mini ≈10 dBm). OS image never built or booted. No physical validation of BLE, RF, motors, ≤5 kg mass (battery excluded) or 2 h autonomy. Pricing incomplete. Anything claiming otherwise is a defect: report it.
