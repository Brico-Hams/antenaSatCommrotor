PortableSatStation · PROTOTIPO NO LIBERADO

PCB, mecánica y control requieren aceptación física. Esta descarga NO certifica seguridad, precisión, RF ni aptitud para conectar motores. Firmware público: carrierVerified=false; sin contraseña WiFi ni token API embebidos. NVS virgen requiere aprovisionamiento USB; NVS previa conserva sus valores. Arranca DISARMED, sin restaurar homing/calibración.

Antes de abrir el puerto serie

  • Desconecta alimentación de motores, drivers y actuadores. Conecta solamente USB al ESP32.
  • Comprueba etiqueta ESP32-DevKitC V4, 38 pines, WROOM-32E (ESP32 clásico). No C3, S3, WROVER/PSRAM ni otro pinout. Comprueba manualmente las dos hileras y orientación.
  • Cierra monitores serie. Confirma tu placa en el selector de permisos; puedes cancelar. No selecciones un equipo desconocido.
  • La instalación reemplaza bootloader, particiones, boot_app0 y aplicación. Si el controlador necesita LittleFS, también reemplaza la UI/TLE almacenada allí. Guarda una copia antes; nunca prometemos conservar una tabla NVS incompatible.

Los archivos separados NO escriben NVS (0x9000–0xdfff). El diálogo presenta “Erase device” sin marcar por defecto. No marques “Erase device” si quieres conservar NVS. Un borrado completo elimina credenciales, datos y configuración y requiere confirmación explícita dentro del instalador. Flashear no constituye homing ni calibración.

Comprobando HTTPS y Web Serial…

Se requiere Chrome o Edge de escritorio con Web Serial. Web Serial no disponible: abre esta página directamente por HTTPS, no en un iframe; revisa permisos/políticas del navegador.

Primer arranque: configuración privada por USB

Con motores desconectados, después de instalar cierra el puerto del instalador y abre una consola USB local a 115200 baudios. Envía una línea JSON {"cmd":"setup"} y sigue el protocolo de configuración del controlador: contraseña AP propia (12–63 caracteres), token API aleatorio propio (24–128 ASCII), y {"cmd":"reboot"}. No pegues credenciales en GitHub, CI ni servicios externos. No marques el carrier verificado hasta completar aceptación física. BLE se habilita sólo mediante provisioning local explícito, no automáticamente. NVS no está cifrada: protege el acceso físico/USB. Raíces TLS vacías rechazan descargas HTTPS; usa carga manual de TLE después de configurar el AP.
